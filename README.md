# FuelPulse

Painel interativo de preços de combustíveis no Brasil e no mundo.

## Recursos
- Preços nacionais e regionais via ANP
- Comparação por região e estado
- Ranking global de gasolina e diesel
- Gráficos interativos com Chart.js
- Cards animados e modal detalhado
- API Flask com cache de 6 horas
- Deploy pronto para Vercel

## Rodar localmente
```bash
pip install -r requirements.txt
python api/index.py
